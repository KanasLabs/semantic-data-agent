负责人：DataSubagent._is_clear_enough()

def _is_clear_enough(question: str) -> bool:
    stripped = question.strip()
    return len(stripped) >= 4 and any(char.isalpha() for char in stripped)
这个规则只拦截空问题、过短问题、纯符号或纯数字问题。后续应升级为“本地规则 + LLM 澄清判断 + Wren 字段/指标匹配”。

关键结论

这两个案例对应同一套项目结构：Data Subagent 做受控编排，WrenAI 做语义层和执行底座，DeepSeek 做 SQL 生成/修复/总结，trace 记录全过程。

ReAct 不是开放式乱调用工具：当前是受控 ReAct。动作集合固定为 context、generate_sql、dry-plan、dry-run、repair_sql、execute、summarize、save_trace。

Trace ID 的作用：每次运行都有唯一 ID，后续可以聚合失败案例、形成 eval、改进 prompt/Wren context/examples，并作为 Codex SDK 后台自改进 runtime 的输入。

下一步：把这类 repair demo 固化成 integration/eval case，并增加更多真实错误类型，例如字段歧义、聚合口径错误、relationship 缺失和 SQL 方言错误。
